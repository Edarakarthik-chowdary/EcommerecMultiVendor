# Ecommerce Multi-Vendor Platform

## 📌 Project Overview

Ecommerce Multi-Vendor is a full-stack web application developed to provide an online shopping platform where customers can browse products, manage their carts, place orders, and manage their accounts.

The application uses React for the frontend and Java Spring Boot for the backend. It follows a REST API-based architecture to communicate between the frontend and backend.
